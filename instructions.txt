#################################################
# INSTRUCTIONS FOR RUNNING THE JAVA APPLICATION #
#################################################

Steps:
  1). BUILD THE APP WITH "mvn package" (SEE README.md), THEN FIND "datagraph-1.0.0-all.jar" IN THE TARGET FOLDER.

  2). SELECT AND DOUBLE CLICK THE APPLICATION.
      [WARNING: THE APPLICATION WILL NOT FUNCTION RUNNING ON THE DATABASE SERVER.]

  3). UPON EXECUTION, THE APPLICATION WILL GREET THE USER WITH A LOGIN PAGE. THE FIRST TEXT FIELD
      IN THE MIDDLE OF THE SCREEN IS FOR INPUTTING THE USER'S USERNAME AND THE SECOND TEXT FIELD
      IS FOR INPUTTING THE USER'S PASSWORD. THE LOGIN CREDENTIALS FOR THE APPLICATION'S LOGIN PAGE
      ARE THE FOLLOWING:
        USERNAME: admin
        PASSWORD: 1234

  4). ONCE INPUTTED, SELECT THE "SUBMIT" BUTTON.

  5). AFTER SELECTING THE "SUBMIT" BUTTON IN THE LOGIN PAGE, THE USER WILL BE MOVED TO THE MAIN PAGE
      WHICH ALLOWS FOR THE INPUT AND VIEWING OF QUERIES. THE INPUT BOX ON THE LEFT-HAND SIDE OF THE
      APPLICATION AGAINST THE BABY BLUE BACKGROUND IS FOR THE INPUT OF SQL STATEMENTS. THE OUTPUT BOX
      ON THE RIGHT-HAND SIDE IS FOR VIEWING THE SQL SERVER'S OUTPUT IN A TABLE FORMAT.

  6). THE USER CAN INPUT AN SQL SCRIPT BY PASTING THE CODE INTO THE LEFT-HAND INPUT BOX OR BY CLICKING
      'OPEN SQL FILE' OPTION IN THE FILE CONTEXT MENU IN THE TOP LEFT CORNER OF THE WINDOW. THE SAME INPUT
      BOX CAN BE CLEARED BY CLICKING THE "CLEAR" BUTTON RIGHT UNDER IT.

  7). ONCE DONE INPUTTING THE SQL STATEMENT OR CODE, CLICK THE "RUN" BUTTON TO EXECUTE THE SQL STATEMENT
      AND CLICK THE "CLEAR" BUTTON UNDER THE OUTPUT BOX TO CLEAR IT.
      
  8). WHEN FINISHED, THE USER MAY SELECT THE "EXIT" OPTION IN THE FILE CONTEXT MENU IN THE TOP LEFT CORNER
      OF THE WINDOW TO EXIT THE APPLICATION OR THE "LOGOUT" OPTION IN THE FILE CONTEXT MENU IN THE TOP LEFT
      CORNER OF THE WINDOW TO RETURN TO THE LOGIN PAGE.
