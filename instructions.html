Instructions for running the java application

Steps:

  • Build the app with mvn package (see README.md), then find "datagraph-1.0.0-all.jar" in the target folder.
  • Select and double click the application.
    warning: The application may not function when it's running on the database server.

  • Upon execution, the application will greet the user with a login page. The first text field in the middle of the screen is for inputting the user's username and the second text field is for inputting the user's password. The login credentials for the application's login page are the following:
    Username:
    Password:
  • Once inputted, select the "Submit" button.
  • After selecting the "Submit" button in the login page, the user will be moved to the main page which allows for the input and viewing of queries. The input box on the left-hand side of the application against the baby blue background is for the input of SQL statements. The output box on the right-hand side is for viewing the SQL server's output in a table format.
  • The user can input an SQL script by pasting the code into the left-hand input box or by clicking 'Open SQL file' option in the file context menu in the top left corner of the window. The same input box can be cleared by clicking the "Clear" button right under it.
  • Once done inputting the SQL statement or code, click the "Run" button to execute the SQL statement and click the "Clear" button under the output box to clear it.
  • When finished, the user may select the "Exit" option in the file context menu in the top left corner of the window to exit the application or the "Logout" option in the file context menu in the top left corner of the window to return to the login page.
